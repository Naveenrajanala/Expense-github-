#  EXPENSE TRACKER

### Smart Expense Tracking and Management System

An easy-to-use Expense Tracker application designed to help users manage daily expenses, monitor spending, and maintain financial records. The application provides separate Admin and User modules with a user-friendly and responsive interface.

##  Live Demo

**Live Application:** https://expense-github.vercel.app

##  Features

- User Registration and Login
- Admin Login and Dashboard
- Add New Expenses
- Edit Existing Expenses
- Delete Expenses
- View Expense History
- Track Total Expenses
- Monitor Daily Spending
- User Dashboard
- Admin Dashboard
- Email Already Exists Validation
- Local Storage Data Management
- Responsive User Interface

##  Modules

The Expense Tracker application consists of two main modules.

### 1. User Module

- User Registration
- User Login
- User Dashboard
- Add Expenses
- Edit Expenses
- Delete Expenses
- View Expense Records
- Track Total Spending
- Manage Personal Expense Details

### 2. Admin Module

- Admin Login
- Admin Dashboard
- View Registered Users
- Manage User Information
- Monitor Application Activities
- Manage Application Details

##  Installation and Setup

Follow these steps to run the project locally.

### Step 1: Install Node.js

Download and install Node.js on your computer.

### Step 2: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 3: Open the Project Folder

```bash
cd expense-tracker
```

### Step 4: Install Dependencies

```bash
npm install
```

### Step 5: Start the Development Server

```bash
npm run dev
```

### Step 6: Open the Application

Open the localhost URL displayed in your terminal.

##  Authentication System

The application provides registration and login functionality.

- New users can register using their details.
- Existing email addresses cannot be registered again.
- Registered users can log in.
- Admin users can access the Admin Dashboard.
- Separate navigation is provided for Admin and User modules.

##  Application Workflow

1. Open the Expense Tracker application.
2. Register a new user account.
3. Log in using registered credentials.
4. Access the User Dashboard.
5. Add, edit, and delete expenses.
6. View expense records and spending details.
7. Admin can access the Admin Dashboard to manage users.
